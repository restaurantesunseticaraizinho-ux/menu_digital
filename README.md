# Menu Digital - Sunset Bar e Restaurante

## 📋 Descrição

Menu digital responsivo desenvolvido para o Sunset Bar e Restaurante, localizado em Icaraí de Amontada - Ceará.

## 📁 Estrutura de Arquivos

```
menu-digital/
├── index.html          # Página principal do menu
├── style.css           # Estilos e design responsivo
├── script.js           # Interatividade e navegação
├── README.md           # Este arquivo
└── assets/
    ├── logo.png        # Logo do restaurante (com transparência)
    ├── menu1.jpg       # Imagem original do cardápio (página 1)
    └── menu2.jpg       # Imagem original do cardápio (página 2)
```

## 🚀 Como Usar

### Opção 1: Abrir Localmente
1. Extraia todos os arquivos mantendo a estrutura de pastas
2. Abra o arquivo `index.html` em qualquer navegador web moderno

### Opção 2: Hospedar Online
1. Faça upload de todos os arquivos para seu servidor web
2. Mantenha a estrutura de pastas intacta
3. Acesse através da URL do seu servidor

## ✨ Características

- **Design Responsivo**: Funciona perfeitamente em desktop, tablet e smartphone
- **Navegação Intuitiva**: Sistema de abas para facilitar a busca por categorias
- **Identidade Visual**: Mantém as cores e logo do restaurante original
- **WhatsApp Integrado**: Botão direto para pedidos via delivery
- **Animações Suaves**: Transições e efeitos visuais modernos
